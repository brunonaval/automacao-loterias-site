Política de Privacidade

Última atualização: 22 de setembro de 2026.

1. Visão geral

A Automação Loterias Caixa é uma extensão independente para Chrome. Seu objetivo é auxiliar o usuário a organizar, validar e transferir combinações previamente preparadas para uma página compatível. O desenvolvedor procura limitar o tratamento de dados ao mínimo necessário para o funcionamento da extensão.

2. Dados armazenados localmente

A extensão usa chrome.storage.local para manter no dispositivo informações operacionais, como rascunhos por modalidade, preferências da interface e formatação, última modalidade usada, estado de processamento, registros técnicos de execuções recentes para proteção contra repetição e resumo da última execução concluída.

3. Acesso ao site compatível

A extensão solicita acesso ao domínio https://www.loteriasonline.caixa.gov.br/* para executar as funções de preenchimento quando o usuário inicia uma ação. Ela lê elementos da página necessários para validar contexto, identificar controles e detectar erros visíveis; também pode acionar controles da interface para realizar o preenchimento solicitado.

A extensão não conclui pagamentos em nome do usuário e não recebe números de cartão. O usuário continua responsável por revisar e concluir qualquer transação no site de destino.

4. Licença, teste e compra

A extensão usa o serviço ExtensionPay para verificar licença, teste gratuito e acesso pago. O ExtensionPay pode fornecer à extensão dados necessários para essa verificação, incluindo endereço de e-mail, status de pagamento, data do primeiro pagamento, data de início do teste, plano e status da assinatura. Parte dessas informações pode ser armazenada localmente pela biblioteca ExtensionPay para manter o estado de acesso.

Quando o usuário inicia login, teste ou compra, dados de conta e pagamento são processados pelo ExtensionPay e pelos provedores de pagamento utilizados por esse serviço, de acordo com as políticas deles. A extensão não recebe nem armazena o número completo do cartão de pagamento.

5. Suporte

Quando o usuário solicita suporte, a extensão pode preparar um relatório técnico. O envio não é automático: o usuário escolhe abrir o Gmail, outro aplicativo de e-mail ou copiar o relatório. O relatório pode conter versão da extensão, versão do Chrome, idioma do navegador, modalidade selecionada, quantidade de linhas, status de conexão com o site, modo de entrada, status da automação, código de erro e data/hora.

O relatório foi projetado para não incluir os números das combinações, dados de pagamento, credenciais de login ou o conteúdo completo da página.

6. Dados que não vendemos

O desenvolvedor não vende dados pessoais do usuário e não os usa para publicidade comportamental, avaliação de crédito ou finalidades não relacionadas à operação, licenciamento e suporte da extensão.

7. Site de documentação

Este site é hospedado no GitHub Pages. Não adicionamos scripts próprios de publicidade ou rastreamento analítico. O GitHub pode tratar dados técnicos necessários para servir as páginas conforme as políticas do próprio GitHub.

8. Retenção e exclusão

Rascunhos e preferências locais podem ser removidos pelo usuário ao limpar os dados da extensão ou desinstalá-la. Mensagens enviadas voluntariamente ao suporte ficam sujeitas à retenção normal da conta de e-mail usada para atendimento.

9. Segurança

A extensão não solicita senhas da conta CAIXA nem armazena credenciais bancárias. Não envie credenciais ou dados de cartão em solicitações de suporte.

10. Contato

Dúvidas sobre privacidade podem ser enviadas para testadortiger@gmail.com.

11. Independência

Este produto é independente e não é afiliado, patrocinado, endossado nem operado pela Caixa Econômica Federal.
