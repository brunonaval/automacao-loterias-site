Main features

The extension is designed to reduce repetitive tasks while keeping the user responsible for reviewing and completing any action on the destination website.

01

Smart paste

Normalizes common input formats such as commas, TABs, hyphens and spaces before validation.

02

Local drafts

Saves combinations and preferences in local browser storage, separately by game mode.

03

Operational safeguards

Checks page context, selected mode and visible error signals before and during entry.

04

Background processing

Processing can continue after the extension popup is closed.

05

Duplicate protection

Helps identify equal or partially repeated batches before a new run.

06

In-extension support

Can prepare a technical report and open Gmail, another email application, or copy the report.

How it works

1
Select a game mode.
The extension adapts the expected input format to the selected mode.
2
Enter combinations you prepared.
The tool validates and organizes the input locally.
3
Open the compatible website and start the action.
The extension acts only after an explicit user action.
4
Review before completing.
Any confirmation, purchase or transaction remains the user's responsibility on the destination website.
