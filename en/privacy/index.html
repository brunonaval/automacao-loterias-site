Privacy Policy

Last updated: September 22, 2026.

1. Overview

Automação Loterias Caixa is an independent Chrome extension. Its purpose is to help users organize, validate and transfer number combinations they have already prepared into a compatible webpage. The developer aims to limit data processing to what is necessary for the extension to function.

2. Data stored locally

The extension uses chrome.storage.local to keep operational information on the user's device, including drafts per game mode, interface and formatting preferences, last selected mode, processing state, recent-run technical records used for duplicate protection, and a summary of the last successful run.

3. Access to the compatible website

The extension requests access to https://www.loteriasonline.caixa.gov.br/* to perform assisted entry when the user initiates an action. It reads page elements needed to validate context, locate controls and detect visible errors, and it can activate interface controls to perform the requested entry.

The extension does not complete payments on the user's behalf and does not receive card numbers. The user remains responsible for reviewing and completing any transaction on the destination website.

4. License, trial and purchase

The extension uses ExtensionPay to verify license, free-trial and paid-access status. ExtensionPay may provide the extension with data needed for this verification, including email address, payment status, first-payment date, trial start date, plan and subscription status. Some of this information may be cached locally by the ExtensionPay library to maintain access state.

When the user starts sign-in, trial or purchase flows, account and payment data are processed by ExtensionPay and the payment providers used by that service under their own policies. The extension does not receive or store the user's full payment-card number.

5. Support

When the user requests support, the extension can prepare a technical report. Sending is not automatic: the user chooses to open Gmail, another email application, or copy the report. The report may include extension version, Chrome version, browser language, selected mode, number of lines, website connection status, input mode, automation status, error code and timestamp.

The report is designed not to include number combinations, payment data, login credentials or full page content.

6. No sale of user data

The developer does not sell personal data and does not use it for behavioral advertising, creditworthiness assessment or unrelated purposes.

7. Documentation website

This site is hosted on GitHub Pages. We do not add our own advertising or analytics tracking scripts. GitHub may process technical data required to serve these pages under GitHub's own policies.

8. Retention and deletion

Local drafts and preferences can be removed by clearing extension data or uninstalling the extension. Messages voluntarily sent to support are subject to the normal retention of the email account used for support.

9. Security

The extension does not request the user's CAIXA account password and does not store banking credentials. Do not send credentials or payment-card data in support requests.

11. Independence

This product is independent and is not affiliated with, sponsored by, endorsed by, or operated by Caixa Econômica Federal.
