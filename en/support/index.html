How can we help?

Report a problem, ask a question, or send a suggestion.

Email support

Describe what happened and, if possible, include your Chrome and extension versions.

testadortiger@gmail.com

Before sending

  • Make sure the intended game page is fully loaded.
  • Tell us which game mode you selected and when the issue occurred.
  • Do not send passwords, card numbers or other credentials.

Technical report

The extension can prepare a technical report when the user explicitly requests support. It may include extension version, Chrome version, browser language, selected mode, number of input lines, website connection status, input mode, automation status, internal error code and timestamp.

The report is designed not to include number combinations, payment data, login credentials or full page content.

Compatibility

The extension depends on the technical structure of the compatible website. Changes made by the destination website may require an extension update.
